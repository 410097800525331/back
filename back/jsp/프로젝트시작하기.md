# 프로젝트 생성
- 프로젝트명: my-jsp
- 프로젝트 구조
	- 패키지 구조
        - src/main/java/controller: *Servlet.java
        - src/main/java/dao: *Impl.java
        - src/main/java/dto: JavaBeans.java
        - src/main/java/util: DBUtil.java

	- 폴더 구조
        - webapp: jsp, html+css+js, ...
        - webapp/WEB-INF/view/member/*.jsp
        - webapp/WEB-INF/view/board/*.jsp


# VSCode + 톰캣 연동
1. 마켓플레이스에서 Community Server Connector 설치
2. 탐색기 창 아래 SERVERS에서 톰캣 서버 추가
        - Create New Server...
                - No, use server on disk 선택
                - 다운로드 받아 압축 해제한 톰캣의 루트 폴더 선택
                - 마침(Finish) 버튼 클릭
3. 톰캣 서버 실행
        - Tomcat 10.x 바로가기 메뉴에서 Start Server 선택
4. 프로젝트 배포
        - Tomcat 10.x 바로가기 메뉴에서 Add Deployment
        - exploded로 배포한 프로젝트 폴더 선택
5. 웹 브라우저를 열고 실행 확인
        - http://localhost:8080/my-jsp/index.jsp
        - http://localhost:8080/my-jsp/hello
